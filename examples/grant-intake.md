# Grant intake

> A reusable meeting playbook: every run starts unticked. Tick items as they're answered (click them, or ⌃⌥C for the next one).
> Durations keep you moving; switch to Count Up (⌃⌥U) if this meeting shouldn't be timed.

- 5m who's applying
  - [ ] organisation name and registration number
  - [ ] contact person, role, email
  - [ ] eligibility: sector, size, years running
- 10m the project
  - [ ] one-line summary
  - [ ] problem and who it helps
  - [ ] measurable outcomes
  - [ ] start and end dates
- 15m budget
  - [ ] total amount requested
  - [ ] itemised lines with quotes
  - [ ] co-funding or matching
- 5m documents
  - [ ] latest financial statements
  - [ ] letters of support
  - [ ] who signs the declaration
- ? anything else
